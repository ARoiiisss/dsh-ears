# 中文显示说明（给 Windows 用户）

这些脚本的输出是 **UTF-8** 的 JSON。但 Windows 控制台默认是 GBK 代码页，
直接 `python ears_xxx.py` 看中文可能显示成 `���`（乱码）。

**数据本身没问题**——你用程序读取、或重定向到 UTF-8 文件都正常。只是想看得舒服，三选一：

1. 运行前切代码页：`chcp 65001`
2. 重定向到文件再打开：`python ears_nowplaying.py > n.json`（文件是 UTF-8）
3. 用 Git Bash / Windows Terminal（默认 UTF-8）

脚本内部已经 `sys.stdout.reconfigure(encoding="utf-8")`，所以**管道给别的程序**不会乱码，
只有"直接在老式 cmd 窗口肉眼看"才会花。
